# Cohort template

Copy this directory to `cohorts/<your-cohort-id>/` and fill in:

1. **`README.md`** (this file) — institution, program, ceremony date, cohort size, theme link.
2. **`personalization.h.example`** — anonymized example showing the data structure your students fill in.
3. (private, do NOT commit) **`personalization.h`** — real student data, generated by Phase 1 tooling.
4. (private, do NOT commit) **`roster.csv`** — list of student IDs ↔ device serial mappings.
5. (private, do NOT commit) **`avatars/`** — per-student dithered avatar PNGs.
6. (private, do NOT commit) **`voice/`** — per-student 30-sec greeting clips.

## Naming convention

Use `<institution>-<program>-<cohort-id>`. Examples:

- `nycu-arete-115`
- `mit-cs-2027`
- `oxford-pgce-2026`
- `nyu-itp-2026`

Lowercase, hyphenated, ASCII only.

## Privacy reminder

The `.gitignore` at the repo root protects you from accidentally committing real student data:

```
cohorts/*/personalization.h
cohorts/*/roster.csv
cohorts/*/avatars/
cohorts/*/voice/
```

If you change these names, update `.gitignore` accordingly.
